# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、运行、复核和报表分发动作。
- `recall_signoffs` 已签核的混箱调拨单据，入库记录只能挂在已签核单据下。
- `recall_events` 按实物先后重放的入库与调拨流水；请求键唯一，作废记录保留审计痕迹。
- `recall_versions` 每次登记生成的候选版本；库存不足时记为暂缓发布并保存原因，快照保存有序流水与按需计算的上下界。
- `recall_ledger` 单行台账锁，串行化补录与版本发布，避免并发生成重复版本号。

新增表随模型自动创建；已有库升级到含 `recall_events.voided_*` 等字段的版本时需要显式迁移。
